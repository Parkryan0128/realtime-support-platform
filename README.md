# Realtime Support Platform

A TypeScript customer support app with workspace isolation, ticket management, and real-time messaging.

## Implementation stages

1. Database schema and TypeScript foundation.
2. Cookie sessions, workspace access, and customer/agent/admin roles.
3. Tickets, assignments, status changes, and durable messages.
4. Socket.IO notifications, reconnect recovery, and Redis fan-out.
5. Customer and agent demo screens.
6. Docker Compose and API, socket, and browser acceptance in CI.

Each stage is tested and committed separately. Documentation stays in this README and one design note.
